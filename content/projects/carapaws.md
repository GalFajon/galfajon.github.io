CaraPaws is a dog-care application I am developing with a teammate for the Global Classroom module at TU Dublin. It helps owners stay connected to their dogs while they are in a sitter's care, through photo updates and access to care information.

The Android application uses React, TypeScript, Vite and Capacitor, with a Node.js and Express API and a PostgreSQL database accessed through Prisma. The application is still in development; the interactive prototype demonstrates the intended owner and sitter flows.

We used Claude Code and the GitHub CLI to turn the project specification into a GitHub Projects plan. I reviewed the resulting issues, technical details and acceptance criteria so that coding agents could work from them.
