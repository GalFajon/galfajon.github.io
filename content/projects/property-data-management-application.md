A Vite-powered React application through which client staff can search for, view and enter property records.

- Integrated the interface with an existing backend using SOAP and XML.
- Implemented permission-aware updates, user activity histories and Excel import/export functionality across all data views.
- Developed a Claude Code skill for the backend's proprietary BASIC dialect, substantially accelerating the development of new API functions.
